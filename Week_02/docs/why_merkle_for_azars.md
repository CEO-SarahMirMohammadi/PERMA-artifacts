# Why Merkle Trees for AZARS Audit

AZARS should not store all operational data directly on the enterprise blockchain because operational databases such as PostgreSQL and MongoDB are more appropriate for high-volume application data. A Merkle Tree allows AZARS to cryptographically summarize a collection of important audit events into a single Merkle Root. If any transaction or audit event changes, the affected leaf hash and its parent hashes change, which ultimately changes the Merkle Root. This provides an efficient cryptographic commitment to the integrity of a group of events while keeping the detailed operational data outside the blockchain. In later versions of AZARS, the Merkle Root can be signed and recorded on the permissioned enterprise blockchain as immutable evidence for audit and compliance.
